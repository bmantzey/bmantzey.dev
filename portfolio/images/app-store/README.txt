PLACEHOLDER - ADD APP STORE SCREENSHOTS HERE

You need to add 3 images to this folder:

1. garmin-dive.jpg
   - From: https://apps.apple.com/us/app/garmin-dive/id1522633851
   - Screenshot from App Store page
   - Recommended: 1170x2532px (iPhone screenshot)

2. schwab-mobile.jpg
   - From: https://apps.apple.com/us/app/schwab-mobile/id407954616
   - Screenshot from App Store page
   - Recommended: 1170x2532px (iPhone screenshot)

3. fieldnet.jpg
   - From: https://apps.apple.com/us/app/fieldnet/id1288019945
   - Screenshot from App Store page
   - Recommended: 1170x2532px (iPhone screenshot)

How to get screenshots:
- Visit the App Store page in your browser
- Right-click on any screenshot → Save Image As...
- Save with the exact filenames above
- Place in this app-store/ folder

Format: JPG or PNG both work
